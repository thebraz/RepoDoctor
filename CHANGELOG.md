# Changelog

## 0.3.3 — 2026-10-06

First public GitHub release of the existing CLI. Adds concise user documentation, a reproducible cycle example, repository metadata, contribution/security guidance, CI and installed-package verification. Runtime rules, schema 1.3 and score formula 1.1 are preserved.

## 0.3.2 — 2026-10-06

English help, reports, diagnostics, finding/context/score explanations and documentation. Commands, scores and analysis contracts unchanged.

## 0.3.1 — 2026-10-06

Organized CLI help with commands, options, examples and exit codes. Help aliases work after a query without scanning the target.

## 0.3.0 — 2026-10-06

Numeric provisional scores for partial analysis. Context factors distinguish application, tests, migrations and tools while retaining evidence. Review priorities and informational notices are separated. Schema 1.3, score formula 1.1.

## 0.2.0 — 2026-10-06

Multilingual text metrics and verified whole-file duplicates; Git ignore layers, generated-file filtering, scopes and a large resource profile. Fixes for editor plugins and Windows aliases. Schema 1.2.

## 0.1.0 — local development

TS/JS discovery and syntax resolution, runtime cycles, file/package usage candidates, size metrics, token duplication, explainable scoring and terminal/JSON/HTML reports. Subsequent local fixes covered credential redaction, `require` writes, script context, built-in package names, Unicode line separators, fractional caps and large metadata lists. Local packaging, an omitted-root CLI and the MIT license were prepared before public release.
